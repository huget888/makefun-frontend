A fast, read-only frontend for make.fun: the live bounty board with each bounty's live pot, entry fee, time left and entries, a bounty's page with its rewards table and rules, its leaderboard, and an account's public profile — each on its own hash route, all from the public API, in vanilla JS and one stylesheet.

## Run it

```sh
node serve.ts
```
